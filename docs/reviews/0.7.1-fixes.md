# Follow-up to the 0.7.1 review

September 10, 2026. Fixes included in release **0.8.0**, on top of `920324c`.
The [original review](0.7.1.md) retains the diagnosis and failing baseline.

All nine findings have implementation or documentation fixes. The five UX
recommendations are implemented. Native Android acceptance remains outstanding;
this is not a release or deployment record.

## Correctness fixes

| Finding | Change | Evidence |
|---|---|---|
| R071-01: concurrent branches disappear | Protocol 7 checks destination and rename-source versions atomically with append. Stale writers reconcile before retrying; retries yield after eight rounds. | Real-server preservation tests with three and five writers, a fresh reader, held replies, offline reconnect, rename/delete/edit, and source changes during rename. Go tests check after body receipt and permit independent entries in a partially refused batch. |
| R071-02: BOM creates extra copies | Keep the BOM when decoding and compare against the original local bytes. | Exact merged bytes with BOM and LF/CRLF; one visible note. |
| R071-03: unchanged metadata hides edits | Invalidate named paths on file events, track Node inode/ctime changes, and provide an explicit full-content verification command. | Same-size/same-mtime replacements reach the peer; event and verification paths are tested separately. |
| R071-04: inaccessible older CLI history | Forward `--before`, validate cursors, and return `nextBefore` in JSON. | CLI pages to an older version; server traverses 503 versions, including deletion, across its 500-entry limit. Existing purge tests remain in the gate. |
| R071-05: misleading restore success | Report server upload separately from delivery to other devices. | Restore-message regressions and updated user guide. |
| R071-06: pointer-only history | Native buttons, selected-state semantics, arrow/Home/End navigation, and focus retention. | Keyboard regressions and native Obsidian captures; TalkBack still needs an actual phone. |
| R071-07: unknown overlapping session omitted | Any unconfirmed live session makes the device checkpoint unknown. | Real-server overlapping-session reproduction now passes. |
| R071-08: inconsistent usage exit | Validate command arguments before opening configuration or a connection; reject ineffective command flags. | CLI usage and recovery suites, including the original exit-code reproduction. |
| R071-09: invalid backup destination | Mount a separate `/backup` destination in the Compose maintenance instructions. | CLI rejects nested destinations and accepts an external snapshot; the full gate also rehearses backup recovery. |

The concurrency change keeps encryption, preserving local writes, manual lock
recovery, and the personal-device scope. Request preconditions use the existing
authenticated TLS connection; they do not claim protection against a malicious
server replaying history. Rename heads include the source's logical deletion,
and Unicode spelling aliases retain their separate wire-path versions.

## UX and mobile layout

- **Review conflicts:** compare original and preserved copy, open either file,
  keep one, or edit a combined version. Revalidate contents before changing
  either file. Preserve typed drafts when resolution or refresh fails.
- **Sync activity:** retain the latest 300 typed events across restarts, with
  filename search and error/conflict filters. Diagnostic export omits filenames;
  the log never stores note bodies, URLs, credentials, or raw server errors.
- **Status menu:** sync, preview, activity, conflicts, history, deleted notes,
  pause/resume, and settings. Pause lasts until resume or restart. The default
  settings still expose only Sync now and Browse deleted.
- **Work previews:** show actual first-sync counts for a populated vault and
  review deletion of multiple files within a removed folder. An explicit CLI
  and plugin preview does not write notes. Sync rechecks the plan before work.
- **History:** bounded, type-aware text previews and diffs. Attachments offer
  restore-to-copy instead of being decoded into a large text pane.

Native light/dark captures cover desktop and phone-width activity, conflicts,
first-sync preview, note history, and attachment history. Layout uses Obsidian's
fonts, spacing, colors, and controls. Mobile actions have 44-pixel targets;
long paths wrap; disclosures keep secondary actions out of the main view.

The visual pass caught and fixed an activity control stretching over filenames,
low-contrast history selection, and a version list that collapsed when its
height became content-based. Screenshot assertions now check readable activity
rows, visible history controls, and horizontal overflow. The capture script
remains in [scripts/screenshots.mjs](../../scripts/screenshots.mjs).

## Performance and code structure

Saved-note delivery to every receiving client had p50/p95 of **22/33 ms** with
two clients and **31/32 ms** with five. These are 20-sample local-server results
with in-memory client vaults, excluding autosave, network latency, and phone
storage. Five fresh readers replayed 1,000 revisions in 11–23 ms; complete
content arrived in 12–25 ms. [Methods and raw data](../research.md#current-measurements--september-10-2026).

Keep recovery scans and the current history protocol. Their measured costs do
not justify a new snapshot protocol or bypassing change detection in this pass.
Active-note work can resume between background files; active sessions use
smaller transfer batches. A single binary exchange remains serialized.

CLI usage validation, activity, conflict review, previews, and store conditional
checks have cohesive modules. Touched comments now describe ambiguous upload
acknowledgements correctly. No fsync, preserving write, or operation-queue guard
was removed to improve a benchmark.

## Verification

`./scripts/check.sh` passed: **30 passed, 0 failed, 0 skipped**. This included
1,645 client tests in 88 files, 15 package-rehearsal tests, 34 stress tests in
6 files, Go tests with race detection, formatting/type checks, Docker packaging,
and the backup-recovery rehearsal. The final native screenshot checks followed
the mobile CSS adjustments; subsequent source edits only shortened comments.
Systemd and mounted-filesystem integration require their Linux CI runners;
local success does not establish CI success for a future commit.
The documentation check resolved 298 local references across 25 documents.
Native history captures also exercised arrow-key selection and focus retention.

`scripts/open-note-smoke.mjs` passed in a disposable native Obsidian vault:
12 updates, two open editors, stable cursors, retained unsaved typing, and intact
undo/redo. Applying updates locally took 30.1–65.0 ms. The temporary plugin and
notes were cleaned up through Obsidian's API.

New tests live in `preservation.stress.ts`, `conditional_test.go`,
`delivery_overlap_test.go`, `usage-history.test.ts`, `cache-events.test.ts`,
`interactive-transfer.test.ts`, and the preview/conflict/activity/history tests.
Existing fault suites cover lost acknowledgements, partial batches, restart,
revocation, slow peers, filesystem seams, and case/Unicode collisions. This is
combined coverage, not a claim to enumerate every cross-product of those faults
with five writers. The original failing patch remains reproducible on `920324c`.
